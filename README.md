SpookySketch

SpookySketch is a small browser-based drawing app with a spooky theme.

The idea is simple: open the canvas, grab a brush, and draw whatever comes to mind.
There is no specific picture to copy and no need to make your drawing look a certain way. The app keeps track of how much of the canvas has been filled, and reaching 50% triggers a spooky response.

What it does
Draw freely on the canvas
Use a pencil or brush
Change the brush size
Pick different colors
Use an eraser
Undo and redo your strokes
Clear the canvas
Save your drawing
Toggle dark mode
Track the percentage of the canvas that has been filled
Trigger a spooky effect when the canvas reaches 50% fill
Includes animated bat effects and other visual details
How it works

The main part of SpookySketch is built around the HTML Canvas API.

You can scribble anything you want on the canvas. JavaScript keeps track of the pixels being drawn and calculates the approximate percentage of the canvas that has been filled.

When the fill percentage reaches 50%, the app reacts with a spooky message or effect.

There is no required drawing or reference image. The whole point is to experiment and see what happens when you fill the canvas.

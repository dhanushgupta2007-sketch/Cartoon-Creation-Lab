SpookySketch 

A simple drawing app with a spooky twist.

Draw the character shown on the screen and try to match it. The closer your drawing gets, the higher your score. Get close enough and... something happens.

 
Features

- Pencil and brush
- Color and brush size controls
- Eraser
- Undo / redo
- Clear canvas
- Save drawing as PNG
- Dark mode
- Drawing match percentage
- Animated bats
- Jumpscare

Built with

- HTML
- CSS
- JavaScript
- Canvas API

Run it

Clone the repo and open `myproject/index.html` in your browser.

```bash
git clone https://github.com/dhanushgupta2007-sketch/Cartoon-Creation-Lab.git
```

Or open it with VS Code + Live Server.

About

I made this for ZoneOut. I wanted to start with something that looks like a normal drawing app and slowly turn it into something creepy.

The drawing match is done using canvas pixel data, not AI image recognition.
